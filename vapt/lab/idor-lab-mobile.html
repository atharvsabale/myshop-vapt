Case 2.1 · Orders IDOR

Open an order by ID

5001 (Alice) 5002 (Bob) 5003 (Alice) 5004 (Bob)

Sign in as Alice, then open 5002 — no ownership check, so Bob's order opens.

Case 2.2 · Account / profile IDOR

View a profile by ID

1001 (Alice) 1002 (Bob)

As Alice, view 1002 — the server trusts the id in the URL, so you read Bob's profile.

Case 2.3 · Custom-app endpoint (no auth)

Call /api/order

This endpoint checks no session. Switch to Logged out and it still returns full order JSON — walk the ids.

A custom-app "admin" page with no role check — any visitor loads it and dumps every customer.
